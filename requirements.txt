# reproducible: a desktop release should ship the version it was tested with.

# resolves to a downgrade. docker-server/Dockerfile deliberately does NOT pin.

# The PDF engine lives in packages/trimitdown-pdf and is published to PyPI as
# trimitdown-pdf (0.1.0, 2026-07-24). This line stays a path anyway: the app
# consumes the module from the working tree so there is exactly one copy of it
# in this repo, and a release cannot ship an app built against a different
# revision of the engine than the one beside it. Switching to a version range
# is a separate decision -- it changes what PyInstaller bundles and what the
# Docker image resolves, and it is not a documentation edit.
# Plain path, not -e: PyInstaller bundles a normally-installed package, an
# editable install it cannot follow.
# For local development install it editable on top -- see DEVELOPMENT.md.
./packages/trimitdown-pdf
